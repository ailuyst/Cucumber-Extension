# Change Log

## 0.0.1

Initial preview release.

- Added VS Code Test Explorer support for Cucumber/Gherkin feature files.
- Added discovery for nested `.feature` files with debounced refresh.
- Added Cucumber CLI execution for all tests, features, scenarios, Scenario Outlines, and example rows.
- Added Cucumber message NDJSON report parsing.
- Added step-level status, duration, error, stack trace, and attachment/log details.
- Added Scenario Outline Examples rows as individual TestItems.
- Added safe Webview details panel, copy details, and reveal source commands.
- Added sample workspace, manual test guide, and release checklist.
